# 播浪

中文名：**播浪** · 前缀 `livewave` · 端口 **6400 / 11400**

## 骨架

**互动事件入流 → 事件时间水位线推进 → 热度窗关闭发射 → 迟到修正/撤回 → 窗输出与撤回互证**

皮：直播间点赞/送礼互动。去皮是事件时间窗计算 + 允许迟到与撤回，不是直播运营后台 CRUD，不是点击会话空闲切开。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6400
# 入流 → 灌「准时热度样例」→ 水位线/热度窗 → 再灌「迟到修正样例」看撤回 → 贯验
# 「迟到修正」页可一键跑演练：首修 / 二修两跳 / 并发不半截 / 故障注入回滚
```

## 允许迟到策略（已实现 · 甲口径）

**口径：原地改窗合计并写撤回单**，全局唯一贯彻。

| 环节 | 行为 |
| --- | --- |
| 判定 | 水位 < 窗止 + 允许迟到 ⇒ 该关闭窗仍可接受迟到修正；否则旁路 |
| 修正 | 关闭窗行上累加点赞/送礼/笔数，版本 +1 |
| 证据 | 同事务写撤回单：旧值→新值、旧笔数→新笔数、旧版本→新版本、触发事件、批次 |
| 对外读 | 窗表现行合计（当前值） |
| 历史 | 窗表不留历史；旧合计经撤回单链逐跳回溯（两跳可查） |
| 原子性 | 改窗、撤回、事件落库、水位推进同一 `BEGIN IMMEDIATE` 事务 + 进程内写锁；任一步失败整批回滚 |
| 互证 | `窗贯验` 校验合计/笔数、撤回链逐跳衔接、末跳=窗表现行、旁路不挂窗键 |

只读接口：

- `GET /api/迟到修正` — 已关闭窗一览：窗键、允许迟到界、水位、版本、修正次数、当前合计、`valid`
- `GET /api/迟到修正/明细?窗键=…` — 单窗证据：撤回链、历史合计、`valid`
- `POST /api/演练/迟到修正` — 四段演练（见下）

已知能力边界：连续迟到修正后，**只有经撤回链**才能取到历史旧合计；窗表本身不保留历史快照。

## 主链对象

| 对象 | 作用 |
| --- | --- |
| 互动事件 | 带事件时/处理时的点赞送礼 |
| 水位线 | 每房事件时水位 + 允许迟到秒 |
| 热度窗 | 翻滚窗；开启累计，关闭发射 |
| 撤回单 | 已关闭窗被允许迟到事件修正（旧值→新值、旧版本→新版本） |
| 旁路匣 | 超允许迟到 |
| 窗贯验 | 窗合计 ↔ 事件合计 ↔ 撤回链逐跳衔接 |

## 空桩（邻题扩展）

双钟水位线、撤回合并替换、房间级水位线、滑动窗切分、送礼加权热度、关窗并发半截、水位线回退禁改、旁路升格重放、多房串扰隔离、空窗发射策略、撤回幂等键、处理时乱序缓冲、窗键对齐互证、热度上限截断、开播闭播切流。
